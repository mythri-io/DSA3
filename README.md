The Multilingual Keyword Detection Search Engine is a DSA-based project designed to efficiently search multiple keywords simultaneously within large text datasets. The project uses the Aho–Corasick algorithm, which combines a Trie data structure, failure links, Queue, and BFS traversal to perform multi-pattern string matching efficiently. Unlike traditional approaches that search for each keyword separately, the proposed engine scans the text efficiently and identifies all occurrences of the given keywords. It supports Unicode and multilingual text, including languages such as English, Telugu, and Hindi, and provides information such as matched keywords, occurrence counts, and matching positions. The project demonstrates the practical application of advanced Data Structures and Algorithms in large-scale text processing and efficient pattern searching.
